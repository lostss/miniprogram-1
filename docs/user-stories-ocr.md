# OCR 保单识别 — 用户故事

> 产品：保小秘 · 生成时间：2026-07-05

---

## US-1: 拍照上传保单

**Title:** 拍照上传保单

**Description:** As a 保险代理人, I want to 用手机拍照或从相册选择保单照片（最多 9 张）, so that 快速录入客户保单信息，无需手动输入。

**Design:** OCR 三态蒙层（等待/识别中/完成）+ 浮层预览卡片

**Acceptance Criteria:**
1. 用户可以从相机拍照或从相册选择图片，最多 9 张
2. 选图后自动压缩到 quality=65，减少上传流量
3. 压缩完成后自动上传到云存储
4. 上传过程中显示进度状态
5. 上传失败时 Toast 提示重试，不阻塞其他图片

---

## US-2: 自动 OCR 识别保单

**Title:** 自动 OCR 识别保单

**Description:** As a 保险代理人, I want to 系统自动对上传的保单图片进行 OCR 识别, so that 保单信息（保单号、产品名、保额、保费等）被结构化提取。

**Design:** 批量识别状态 + 结果预览卡片

**Acceptance Criteria:**
1. 图片上传成功后自动触发 OCR 识别，每批 5 张并发处理
2. OCR 识别调腾讯云 GeneralFastOCR 获取原始文字
3. AI 模型从 OCR 文本中提取结构化字段：保单号、保险公司、生效日期、投保人、被保人、产品名、险种、保额、保费、缴费期、保障期、受益人、出生日期
4. 个别图片识别失败自动重试 1 次，重试仍失败则跳过该张
5. AI 提取失败时返回原始 OCR 文本，confidence=0.5，强制走确认流程

---

## US-3: 置信度分流

**Title:** 置信度分流

**Description:** As a 保险代理人, I want to 系统根据 OCR 置信度自动判断是否需要我确认, so that 高置信度（≥0.95）的保单直接入库，低置信度的弹卡让我核实修改。

**Design:** 暖金下划线标注 AI 不确定字段 +「确认」「修改」双按钮

**Acceptance Criteria:**
1. 所有字段置信度均 ≥0.95 → 自动写入 policies 集合，跳过确认步骤
2. 存在任一字段 <0.95 → 弹出确认卡片，暖金下划线标注低置信字段
3. 确认卡显示「确认」（全盘接受）和「修改」（逐项编辑）两个按钮
4. 用户点击修改后可逐字段编辑并重新提交
5. 提交后走相同入库流程

---

## US-4: 家庭成员自动匹配

**Title:** 家庭成员自动匹配

**Description:** As a 保险代理人, I want to OCR 识别后系统自动将投保人/被保人与已有家庭成员匹配, so that 无需手动关联保单和成员。

**Design:** 自动匹配 + 新建成员提示

**Acceptance Criteria:**
1. OCR 提取的投保人/被保人姓名与当前家庭已有成员做模糊匹配
2. 匹配成功 → 保单自动关联该 member_id
3. 匹配失败 → 自动创建新成员（以识别姓名为名，role 为空）
4. 投保人=被保人时仅创建一条成员记录
5. 姓名相同但 role 不同视为不同成员
6. 同步写入 birth_date+计算 age 到成员信息

---

## US-5: 首次上传自动建档

**Title:** 首次上传自动建档

**Description:** As a 保险代理人, I want to OCR 后系统自动创建客户家庭档案, so that 无需手动输入客户信息就能开始使用。

**Design:** 自动跳转报告页

**Acceptance Criteria:**
1. 首次上传保单时，以投保人姓名为家庭名称自动创建 families 记录
2. 自动创建包含投保人的初始成员列表
3. 创建完成后直接跳转到报告页
4. 多张保单的投保人不同时，提示用户选择匹配已有家庭或新建
5. 已存在的家庭直接追加保单，不重复建档

---

## US-6: OCR 后自动触发报告刷新

**Title:** OCR 后自动触发报告刷新

**Description:** As a 保险代理人, I want to 保单入库后系统自动重新生成保障报告, so that 报告页展现最新的保障分析。

**Design:** 静默后台刷新 + 顶部暖金提示

**Acceptance Criteria:**
1. OCR 入库完成后自动触发 reportAI 重新生成报告
2. 报告生成在后台进行，不阻断用户操作
3. 生成完成后顶部暖金条提示「报告已更新」，3 秒后淡出
4. 报告页的结论/分析/建议章节实时反映新保单数据
5. 报告生成失败时静默重试 1 次，不提示错误
